#### **✦ Research Overview**
**The Moore Signal Archive LLC** bridges citizen-science astronomy with cosmic poetry and visual art. While active research focuses on All-Sky classifications via **[Zooniverse](https://www.zooniverse.org/about)**, this repository also archives historical exoplanet transit curves modeled for **[Exoplanet Watch](https://science.nasa.gov/citizen-science/exoplanet-watch/exoplanet-watch-overview/)** using the **[EXOTIC](https://science.nasa.gov/citizen-science/exoplanet-watch/exotic/)** Python pipeline.

> *Note: Independent data-art archive utilizing public-domain astronomy datasets. Not affiliated with, funded by, or endorsed by NASA, AAVSO, or Zooniverse.*
